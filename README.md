# 投篮训练助手（手机版）

浏览器里跑的手机端实时投篮分析。**所有计算都在手机上完成**，不需要服务器、不需要电脑。

- 摄像头 → MediaPipe 姿态识别 → 出手检测 / 动作指标 / 问题提示
- 进球判定（球轨迹跟踪）
- 分析逻辑与电脑端**共用同一份 Python 代码**（浏览器里用 Pyodide 运行）

打开页面 → 允许摄像头 → 点「标定篮筐」点一下筐心并调好框大小 → 开始投篮。

第一次打开需要联网（要下载约 70MB 的运行环境），之后会被缓存，**断网也能用**。
建议「添加到主屏幕」，用起来更方便、缓存也更不容易被系统清理。

源项目在本地维护，这个仓库是自动生成的发布副本。
